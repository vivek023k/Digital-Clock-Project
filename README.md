# 🕐 Digital Clock

A simple and clean **Digital Clock application** that displays the **current date and time** in real time.

This project is created to practice Java programming, GUI development, and working with date and time.

## ✨ Features

* 🕒 Displays the **current time**
* 📅 Displays the **current date**
* 🔄 Updates the time continuously
* 🖥️ Simple and clean GUI
* ⚡ Lightweight and easy to run
* ☕ Built using **Java**

## 🛠️ Technologies Used

* **Java**
* **Java Swing**
* **AWT**
* **Date & Time API**

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/digital-clock.git
```

### 2. Open the Project

Open the project in your preferred Java IDE, such as:

* IntelliJ IDEA
* Eclipse
* VS Code
* NetBeans

### 3. Compile and Run

Compile the Java source file and run the main class.

```bash
javac DigitalClock.java
java DigitalClock
```
